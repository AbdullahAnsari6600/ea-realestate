# Dubai Dream Property Guide

Build a premium, luxury, fully responsive multilingual real estate website for Early Approve Real Estate Group™, Dubai.

Website: https://earealestategroup.com/

Technology

React + Vite + TypeScript.

Tailwind CSS.

React Router.

Framer Motion.

Lucide React.

Design

Create a sophisticated international luxury real estate aesthetic using deep charcoal/navy, white and subtle champagne-gold accents. Use elegant typography, cinematic Dubai photography, smooth animations, spacious layouts and premium property cards.

Properties

Create beautiful property cards and individual property detail pages. Include property name, type, location, description, price range, multiple image galleries and video previews.

For now, use realistic sample data stored in local TypeScript/JSON files. Structure the property components and data services so they can later connect easily to a real backend.

Other features

Investment opportunities page.

Book a Viewing form.

Custom enquiry form with name, email, country-code phone, buying/renting, budget, preferred location, property type and contact method.

Careers page with application form.

Working mortgage and rental yield calculators.

FAQ accordion.

WhatsApp contact button.

Branding and positioning

Present Early Approve as an established, experienced and professionally connected business with financial expertise and an experienced five-member team. Never describe the company as a newcomer or startup.

Languages

Support English, Arabic and French using:

en.json

ar.json

french.json

Implement a language selector, persistent language preference and complete Arabic RTL support.

Important development restrictions

FRONTEND ONLY.

No backend.

No database.

No Prisma.

No Express.

No authentication.

No API integration.

No Cloudinary integration.

No server-side functionality.

Use local sample data and frontend interactions only. Forms should have frontend validation and simulated success messages.

Keep the architecture modular and reusable so backend integration can be implemented later without rebuilding the frontend.

Build a polished, complete website with all pages, responsive layouts, working navigation and functional frontend interactions. Do not leave empty sections or non-functional buttons.
